# CORTEX-PRIME — Complete Mathematical Specification (Bio-Aligned, Locally Implementable)

This document defines the **minimal, irreducible cortical computation** as a standalone mathematical object.

Everything here corresponds to known cortical principles.

Nothing here relies on gradients, losses, tokens, or optimization objectives.

All operations are **local or low-rank**, with no global synchronization primitives.

---

## 1. State (Only State That Exists)

\[
H_t \in \mathbb{R}^{k \times n}
\]

- \(n\): number of cortical neurons  
- \(k\): internal vector state per neuron  

Each neuron is **vector-valued**, not scalar.  
There are no layers, no heads, no modules.

---

## 2. Input (Broadcast Injection)

Input enters cortex diffusely:

\[
H_t \leftarrow H_t + E_t
\]

Where:
- \(E_t \in \mathbb{R}^{k \times n}\) is a broadcast input field
- Often low-rank or spatially smooth
- No addressing, no selection, no routing

Cortex does **not** decide where input goes.  
Competition decides what survives.

---

## 3. Fixed Cortical Dynamics

### 3.1 Recurrent Mixing (Low-Rank Coupling)

\[
X = H_t \, A \, B
\]

- \(A \in \mathbb{R}^{n \times r}\)
- \(B \in \mathbb{R}^{r \times n}\)
- \(r \ll n\)

Interpretation:
- diffuse recurrent connectivity
- shared microcircuits
- dendritic mixing

Low-rank structure enforces:
- parameter efficiency
- linear-time computation
- global coordination without global access

---

### 3.1b Sparse Long-Range Connectivity (Small-World Completion)

In addition to low-rank coordination, the cortical sheet includes a **sparse set of long-range excitatory connections**.

Let:
\[
S^{LR} \in \mathbb{R}^{n \times n}
\]

with properties:
- sparsity: \(\mathbb{P}(S^{LR}_{ij} \neq 0) = O(\log n / n)\)
- nonnegative weights
- no global density (bounded degree)
- plastic on a **slow timescale** under the same Hebbian rule

The effective recurrent drive becomes:
\[
X = H_t (A B + S^{LR})
\]

This ensures:
- short average path length
- rapid global information propagation
- biologically realistic small-world topology

No explicit structure is imposed beyond sparsity and plasticity.

---

### 3.2 Neuronal Saturation (Excitation Control)

\[
H_{\text{raw}} = X \odot \phi(|X|)
\]

Where:
- \(\phi(z)\) is saturating (e.g. \(\tanh(z)\), \(\log(1+z)\))
- \(\odot\) is elementwise multiplication

Purpose:
- bound activity
- prevent runaway excitation
- preserve relative magnitudes

---

### 3.3 Lateral Inhibition (Local, Not Global)

Cortex does **not** compute global means.  
Each neuron is inhibited by a **local neighborhood**.

#### Spatial structure
Neurons are indexed by position \(i\) on a cortical sheet.

Let \(K_{ij}\) be a fixed local inhibitory kernel:
- Gaussian
- difference-of-Gaussians
- compact support

#### Subtractive inhibition (local mean)

\[
\mu_i
=
\sum_{j \in \mathcal{N}(i)} K_{ij}\, H_{\text{raw},j}
\]

#### Divisive inhibition (local gain control)

\[
\gamma_i
=
\sum_{j \in \mathcal{N}(i)} K_{ij}\, |H_{\text{raw},j}|
\]

#### State update (per neuron)

\[
H_{t+1,i}
=
\frac{H_{\text{raw},i} - \alpha \mu_i}{\epsilon + \beta \gamma_i}
\]

Effects:
- neurons compete locally
- sparse representations emerge
- scale is stabilized
- global balance emerges **statistically**, not explicitly

> Representation = neurons that survive **local** inhibition.

## 4. Prediction (Implicit, Not Supervised)

Cortex predicts **its own next state**:

\[
H_t \rightarrow H_{t+1}
\]

No logits.  
No probabilities.  
No explicit outputs required.

Optional diagnostic readout:

\[
\delta = H_{t+1}^{(\text{readout})} - \text{target}
\]

- \(\delta\) is a vector
- local
- never backpropagated

## 5. Learning Rule (Single Hebbian Plasticity)

### 5.1 Hebbian Update (Oja-Style)

Let:
\[
X = H_t,\quad Y = H_{t+1}
\]

Core Hebbian form:
\[
\Delta W \propto X Y^\top
\]

Stabilized (Oja):
\[
\Delta W \propto X Y^\top - Y Y^\top W
\]

Properties:
- strengthens correlated activity
- suppresses redundancy
- prevents divergence

---

### 5.2 Low-Rank Plasticity (Biological Constraint)

Connectivity factorization:
\[
W = A B
\]

Plasticity acts only through low-rank factors:

\[
\Delta A
=
\eta_t \odot
\left(
Y^\top (X B^\top - Y A)
\right)
\]

- local
- symmetric
- linear-time
- biologically plausible

---

### 5.3 Sparse Long-Range Plasticity (Slow Timescale)

For \(S^{LR}\), apply the **same Hebbian rule** but with:
- much smaller \(\eta^{LR}\)
- optional activity thresholding
- infrequent updates

This mirrors white-matter tract refinement and developmental pruning.

## 6. Neuromodulation (Explicit Chemical Field Definition)

Learning rate is **not an objective**.  
It is gated by **chemical fields**.

### 6.1 Chemical Signals

Neuromodulators are spatial fields:

\[
\text{DA}_t,\ \text{ACh}_t,\ \text{NE}_t,\ \text{5HT}_t \in \mathbb{R}^{n}
\]

Interpretation:
- **DA** → reinforcement / association
- **ACh** → plasticity & attention
- **NE** → arousal / gain
- **5-HT** → stability / consolidation

---

### 6.2 Rank Profiles (Fixed Wiring)

Each chemical modulates plasticity along low-rank axes:

\[
d_{\text{DA}}, d_{\text{ACh}}, d_{\text{NE}}, d_{\text{5HT}} \in \mathbb{R}^{r}
\]

Baseline:
\[
b \in \mathbb{R}^{r}
\]

These are **fixed organism parameters**.

---

### 6.3 Explicit Definition of \(f\)

Pre-gated plasticity field:

\[
Z_t
=
\text{DA}_t d_{\text{DA}}^\top
+
\text{ACh}_t d_{\text{ACh}}^\top
+
\text{NE}_t d_{\text{NE}}^\top
+
\text{5HT}_t d_{\text{5HT}}^\top
+
\mathbf{1}_n b^\top
\quad \in \mathbb{R}^{n \times r}
\]

Neuromodulated learning-rate field:

\[
\boxed{
\eta_t
=
\eta_{\max}\, \sigma(Z_t)
}
\]

Where:
- \(\sigma\) is elementwise sigmoid
- \(\eta_{\max} > 0\) bounds plasticity

Plasticity is **chemically gated, spatially structured, and low-rank**.
